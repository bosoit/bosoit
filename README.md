## 🧑‍💻 略歴・PR

- 1988年より数人規模（退職時は50人規模）の独立系ソフトハウスに入社し、制御系（ASM、C、VBなど）および業務系（VBA、C#、VB.NET、JavaScript、Java、SQLなど）のソフトウェア開発に従事。  
- 2010年より同社にて取締役としてSES営業・人事（評価・採用）・ISMSセキュリティ管理責任者等に従事しながら、受託開発案件のマネジメントを担当。  
- 2017年よりソフトウェア開発への回帰を希望し、フリーランスエンジニアとしての活動を開始。

企業在職中は、PG→SE→TL→PM→役員と各ポジションを経験していますので、広い視点で開発に対応できます。

メインスキル以外の言語や環境へのキャッチアップも得意としており、、メインスキルに限定せず対応可能です。
また、ClaudeCodeやCursorを活用して開発効率化も進めています。  

システム開発においては技術力だけでなく、以下の点を大切にしています。

- 💬 会話がしやすい人柄であること
- 🎯 お客様の意図を想像すること
- 🤝 お客様や担当者間で発生する隙間を埋めるための主体的な行動
- 💰 コスト意識を持った行動
- 👁️ ユーザビリティや仕様で気づいた点の都度共有
